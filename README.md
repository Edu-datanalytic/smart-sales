# Smart Sales — Sales Data Analysis

## Project overview

Smart Sales is a data analytics portfolio project focused on exploring sales data, identifying business trends, and extracting insights using SQL and Power BI.

The goal is to transform raw sales data into useful information that supports business decision-making.

## Objectives

- Analyze data quality and identify potential inconsistencies.
- Calculate net sales after discounts.
- Analyze monthly sales trends.
- Identify top-performing products and categories.
- Analyze customer revenue and purchasing activity.

## Tools and technologies

- **SQL:** Data exploration, quality checks, joins, aggregations, and business analysis.
- **SQLite:** Database querying.
- **Power BI:** Planned for data visualization and dashboard development.

## SQL analysis

The SQL queries cover:

- Data quality checks.
- Monthly net sales.
- Revenue by product.
- Revenue by category.
- Customer revenue analysis.
- Number of orders per customer.

Net sales are calculated by applying the discount to each order item.

**In progress.** SQL analysis has been developed. Power BI visualization and further project documentation are planned.
